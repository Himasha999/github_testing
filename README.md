# 🌸 Bloom & Blossom Flower Shop System

A modern, responsive, aesthetic online Flower Shop Web Application crafted with smooth micro-interactions, dynamic cart calculation, user authentication, and high-quality floral imagery.

## 📁 Directory & File Structure

```text
flower_shop_system/
├── .gitignore                         # Git ignored items
├── README.md                          # Project documentation
│
├── index.html                         # Home / Flower Catalog Page
├── login.html                         # Customer Login Page
├── register.html                      # Customer Registration Page
├── cart.html                          # Cart & Order Confirmation Page
├── success.html                       # Order Success Confirmation Page
│
├── css/
│   └── style.css                      # Modern CSS Styling & Glassmorphism Theme
│
├── js/
│   ├── app.js                         # Main Web App Logic & Dynamic UI
│   ├── auth.js                        # Authentication & Session Management
│   └── api.js                         # Database / Inventory API Layer
│
└── assets/
    └── images/                        # High-resolution flower images
        ├── rose.jpg
        ├── lily.jpg
        └── orchid.jpg
```

## ✨ Features
- **Dynamic Flower Catalog**: Real-time category filtering (All, Roses, Lilies, Orchids, Special Bouquets), live search, price sorting.
- **Interactive Cart**: Dynamic quantity updates, promo code support, delivery fee calculation, item deletion.
- **User Authentication**: Local-session based registration, login, user status navbar display, persistent storage.
- **Order Flow**: Streamlined single-click checkout with visual receipt & celebration feedback on order success.
- **Responsive & Elegant UI**: Soft pastel rose gradients, glassmorphism cards, Google Outfit font, and micro-animations.

## 🚀 How to Run
1. Open `index.html` in any web browser or serve with live-server / static server (`npx http-server .`).
2. Explore flowers, filter categories, register/login, add items to cart, and complete orders!
